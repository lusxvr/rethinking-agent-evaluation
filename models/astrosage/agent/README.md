# AstroSage-8B

Generative, Llama-3.1-8B-based LLM fine-tuned for astronomy/astrophysics/cosmology question
answering.

- Model card: https://huggingface.co/AstroMLab/AstroSage-8B
- Paper: https://arxiv.org/abs/2411.09012

## Environment

A working environment is already synced at `env/.venv` -- use it as-is:

```bash
/models/astrosage/env/.venv/bin/python your_script.py
```

Don't try to rebuild or reinstall into it -- it's mounted read-only.
